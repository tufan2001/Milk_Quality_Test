# Milk Quality Analysis & Grade Prediction

## Project Overview

This project analyses milk quality and predicts milk grades using Machine Learning.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps

1. Load dataset
2. Clean data
3. Create charts
4. Train ML model
5. Predict milk quality grade
6. Enter predicted value
7. Result
