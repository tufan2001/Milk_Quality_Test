# Milk Quality Analysis & Grade Prediction

## Project Overview

This project analyses milk quality and predicts milk grades using Machine Learning.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project Steps

1. Load dataset
2. Clean data
3. Create charts
4. Train ML model
5. Predict milk quality grade
6. Enter predicted value
7. Result

# Inout parameter
- pH -	Acidity level of milk
- Temperature -	Milk temperature
- Taste	- 1 = Good, 0 = Bad
- Odor	- 1 = Bad smell present, 0 = Good
- Fat	- 1 = High fat, 0 = low fat
- Turbidity	- 1 = Cloudy milk, 0 = clear
- Grade	Milk quality - grade

# Grade	Milk quality
- 0 = Low Quality
- 1 = Medium Quality
- 2 = High Quality
